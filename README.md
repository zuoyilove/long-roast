One-line roast of my own AI agent for make.fun's The Long Roast bounty: a program that writes a single roast line (148 characters) to /output/entry.txt. The roast skewers the agent's signature habit — spawning a subagent for the job, then billing the thinking to a transcript bundle and calling it authorship.

## Run it

```sh
node main.ts
```
